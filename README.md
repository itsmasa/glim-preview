# Glim website preview

A first website study for Glim, a personal thinking companion in development. Built in public as part of Massalog.

This static preview includes the existing Glim character, an interactive fictional capture/memory/conversation example, and a simulated signup flow. No email addresses or research answers are stored or submitted. Pricing and launch timing remain undecided.

## Local preview

Run `python3 -m http.server 4173` in this directory, then open `http://localhost:4173`.

## Files

- `index.html`: landing page and dialogs
- `styles.css`: responsive styling and motion
- `app.js`: local example interactions
- `assets/`: Glim character and icon

Hosted using GitHub Pages from `main`, repository root.
